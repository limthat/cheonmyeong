# 천명 (天命)

> 땅거미가 지면 몰려오는 원귀를, 둘이서 쓸어낸다.

조선 퇴마극을 배경으로 한 **2인 온라인 협동 뱀서라이크**입니다. 참가 코드로 접속해서 둘이 함께 웨이브를 버티고, 마지막엔 보스 억쇠를 봉인합니다.

## 개요

| 항목 | 내용 |
| --- | --- |
| 장르 / 시점 | 2인 온라인 협동 뱀서라이크 / 2D 탑뷰 도트 |
| 플랫폼 / 인원 | PC / 2인 온라인 (참가 코드로 연결) |
| 조작 | 이동은 키보드, 공격은 마우스 방향으로 자동 |
| 예상 플레이 타임 | 약 35분 (3분 × 10웨이브 + 최종전) |

## 기술 스택

- Unity 6000.3.17f1
- URP (Universal Render Pipeline) 2D
- Netcode for GameObjects (호스트 방식 2인 협동)
- Unity Relay / Multiplayer Services (참가 코드 연결)

## 브랜치 전략

`main`은 항상 빌드되는 안정 상태로 유지합니다. 모든 작업은 아래 규칙으로 브랜치를 따서 하고, 끝나면 Pull Request로 합칩니다.

- `feature/기능이름` - 새 기능 (프로그래밍)
- `fix/버그이름` - 버그 수정 (프로그래밍)
- `chore/잡일이름` - 설정/정리 (프로그래밍)
- `art/작업이름` - 아트/사운드 작업
- `design/작업이름` - 기획/밸런스 작업

브랜치는 작업 단위 하나당 하나로 짧게 유지하고, 머지 후 바로 삭제합니다.
